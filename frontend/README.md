# Frontend – Todo List

React + Vite consumindo a API em `../backend`.

## Rodar
```bash
# 1. backend (MySQL com schema.sql aplicado)
cd backend && npm install && npm run dev      # http://localhost:3333

# 2. frontend
cd frontend && npm install && npm run dev     # http://localhost:5173
```
A URL da API fica em `.env` (`VITE_API_URL`, padrão `http://localhost:3333`).
